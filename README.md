## I'm Govind — Senior Software Engineer, React Native <img src="https://media.giphy.com/media/WUlplcMpOCEmTGBtBW/giphy.gif" width="30">

I build mobile applications with React Native, and I'm currently exploring the intersection of **mobile development and on-device AI** — running useful LLMs directly on consumer hardware instead of relying entirely on cloud APIs.

My focus is the practical path: **Model → Mobile Runtime → Device Performance → User Experience.**

---

### 🔨 Currently building

**KeepDoc** — a fully offline, India-localized personal document assistant. Scan or upload a document, an on-device LLM summarizes it, files it, and makes it searchable — all without the data ever leaving the phone. Built for budget Android hardware (4–6GB RAM), with support for asking questions in Hindi/Hinglish about documents written in English.

Stack: React Native + Expo, [llama.rn](https://github.com/mybigday/llama.rn) for local model inference.
