## 🔨 Building — KeepDoc

<table>
<tr><td>

**A fully offline, India-localized document assistant.** Scan or upload a document — an on-device LLM summarizes it, files it, and makes it searchable. Nothing ever leaves the phone. Ask questions in Hindi/Hinglish about a document written in English. Tuned to run on budget Android hardware (4–6GB RAM).
